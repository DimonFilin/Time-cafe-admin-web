## Две группы размещения

### 1. Конструкция (`planGroup: structure`)

Стена → сегменты, толщина, склейка углов.  
Комната → полигон зоны.  
Окно → на стене, вырез на всю толщину.  
Дверь → на стене; символ с полукругом открывания; тип: обычная / с кодовым замком; направление: наружу / внутрь / в обе.  
Лестница → на плане: прямоугольная, круглая, «половина в двух комнатах» (паттерн `stair-half`).

Переключение инструментов: панель «Конструкция» + кнопки подгруппы. На canvas остаются только **корректор** (✎), **удаление** (🗑) и масштаб.

### 2. Интерьер (`planGroup: interior`)

Стол / стул — один режим с переключением типа без смены группы.  
Диван (прямой / угловой), туалет, умывальник, шкаф, ТВ настенный, ТВ с подставкой, мультиборд.

ТВ с подставкой и мультиборд: `skipCollision: true` — не блокируют сохранение при пересечении с другой мебелью.

## Режим «Изменение» (EDIT)

- **Двойной клик** по объекту — изоляция на плане и панель свойств в **верхней полосе** (`LayoutEditInspector`): зона комнаты (назначение комнаты, название, вместимость, статус), стол, стул, окно, дверь, интерьер, лестница, толщина стены.
- Пока стол **изолирован** двойным кликом (`editFocus.type === 'table'`) — **пауза** цикла перекрывающихся объектов (4 с).
- Поворот (↻): стол, стул, зона, объекты интерьера, лестница. Стены, окна, двери — без поворота. Лестницы и интерьер рисуются с `furnitureTransform` / `rotationDeg`.

---

## Удаление

`layout-pick.ts`: приоритет сверху вниз — fixture, стул, стол, дверь, лестница, окно, стена, зона.  
Клик и рамка удаляют все типы, включая двери, лестницы и объекты интерьера.

## Названия на плане

| Объект             | Поле в UI                 | На canvas             |
| ------------------ | ------------------------- | --------------------- |
| Стол / стул        | `LayoutPlacementPanel`    | подпись у объекта     |
| Дверь              | «Название» в панели двери | —                     |
| Лестница           | «Название»                | над объектом          |
| Интерьер (FIXTURE) | «Название на плане»       | по центру (`fx.name`) |

При размещении интерьера: `name = ввод.trim() || defaultFixture(kind).name` — можно отличить, например, «ТВ зал» от «ТВ с тумбой».

## Лестницы (схема)

- **Прямоугольная** — половина ступенек вверх, половина вниз.
- **Круглая** — дуговые ступени по окружности.
- **Между комнатами** — два клика (сегмент вверх + сегмент вниз), пунктир между ними.

## Сохранение

`PUT /api/cafe-layout/cafes/:id/editor` — `elements[]` собирается из текущей геометрии (стены, мебель, двери, лестницы, объекты интерьера). Типы:

`WALL`, `ROOM_ZONE`, `TABLE`, `CHAIR`, `WINDOW`, `DOOR`, `STAIR`, `SOFA`, `TOILET`, `SINK`, `CABINET`, `TV`, `WHITEBOARD`

Перед сохранением проверяются пересечения стен, зон и **всех размещённых объектов** (столы, стулья, интерьер, лестницы) с учётом `rotationDeg`; ТВ/мультиборд с `skipCollision` не участвуют. В диалоге конфликтов подсвечиваются и шкафы, и прочий интерьер.

## Черновики на canvas

При наведении показываются ghost-превью для: стол/стул, окно, дверь, лестница, объект интерьера.

## Фон плана (PNG / JPEG)

В верхней панели редактора: «Загрузить фон» — файл сохраняется в `layout.schema.planBackgroundImage` (data URL). На canvas фон рисуется под сеткой; комнаты (зоны) размечаются поверх. Прозрачность регулируется ползунком.

## Тарификация комнат

В блоке «Комнаты» для каждой комнаты в `metadata.billing`:

- почасовая (`hourlyRateRub`, округление вверх до часа);
- поминутная (`minuteRateRub`, цена × минуты).

Можно включить один или оба режима. Мобильное приложение получает тарифы в `GET .../rooms/availability` и считает цену при бронировании.

## Связанные лестницы (half_room)

Сегменты поворачиваются и двигаются отдельно; пунктир между половинками рисуется в мировых координатах (центр → центр) и **не вращается** вместе с символом.

## Полноэкранный режим (⛶)

Кнопка рядом с масштабом на плане. **Esc** — выход.

**Разметка (без наложения панелей):**

1. **Верхняя полоса** (`shrink-0`) — размер поля плана, подсказка по режиму, параметры инструмента (стол, дверь, лестница, название интерьера и т.д.).
2. **Нижний ряд** (`flex flex-1 gap-2`) — слева узкая колонка **«Группа»** + кнопки Конструкция/Интерьер и подинструменты; справа canvas на всю оставшуюся ширину (без `absolute` и `ml-44`).

В обычном режиме те же блоки идут столбцом: настройки → группа инструментов → план.

## Режим «Изменение» для интерьера

Столы, стулья, объекты интерьера (диван, сантехника, шкаф, ТВ) и лестницы: перемещение, поворот (↻), удаление.
